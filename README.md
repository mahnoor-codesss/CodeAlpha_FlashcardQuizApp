# CodeAlpha Flashcard Quiz App

 Project Description
Flashcard Quiz App is a Java console-based application developed for studying and revision purposes. Users can create flashcards containing questions and answers, study them interactively, and manage flashcards easily.

 Features
- Add flashcards
- View flashcards
- Study mode
- Show answers
- Navigate using next and previous options
- Edit flashcards
- Delete flashcards
- File handling for saving/loading flashcards
- Auto-save functionality

Technologies Used
- Java
- OOP Concepts
- File Handling
- VS Code

## How to Run

1. Open the project folder in VS Code
2. Open terminal
3. Compile the program:

```bash
javac FlashcardApp.java
```

4. Run the program:

```bash
java FlashcardApp
```

Important Notes
- Flashcards are automatically saved in `flashcards.txt`
- Keep `flashcards.txt` in the same folder as the Java file
- The application loads saved flashcards automatically
